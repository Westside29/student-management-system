# Student Management System

## 1. Project Description

The Student Management System is a web application developed using React and JavaScript. It allows users to manage student information through a simple dashboard.

## 2. Project Features

- View student records.
- Add new students.
- Edit existing student information.
- Delete student records.
- Validate student information before saving.
- Search for students.
- View student statistics on the dashboard.
- Save student records in the browser using localStorage.
- Use the application on different screen sizes.

## 3. Student Information

Each student record can contain the following information:

- Student ID
- Full Name
- Age
- Email
- Course
- Enrollment Status

## 4. Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Browser localStorage

## 5. How to Run the Project

1. Install Node.js on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Install the required packages by running:

   `npm install`

5. Start the development server by running:

   `npm run dev`

6. Open the local URL displayed in the terminal.

Note: On some Windows PowerShell systems, you may need to use `npm.cmd` instead of `npm`.

## 6. Data Storage

The application uses browser localStorage to save student records. This allows records to remain available after refreshing the page in the same browser, unless the stored data is cleared.

## 7. Production Build

To check and build the project for production, run:

`npm run build`

The generated production files will be placed in the `dist` folder.

This project was developed as part of the DIWA2110 Web Application Development assignment. It demonstrates the use of React components, JavaScript, state management, form validation, and browser storage.
